## The entry

The office printer finally speaks — tired, literal, and quietly passive-aggressive. It has counted every single time you hammered the Print button, and it wants you to know it heard you the very first time.

> You have pressed Print 14 times in the last 40 seconds; I heard you the first time and I am still on page one.

## Run

```bash
python3 main.py
```

This writes the one-line reply to `/output/entry.txt`.
